# Dorm 开发记录

## 原始 Prompt 摘要

- 以 Flutter 和 Dart 为高校 AIGC 应用创新大赛实现可操作的寝室协作原型。
- 首先检测 WSL2，优先在 Linux 原生工作目录交付 Linux x86_64，再处理 Windows x86_64 与 Android ARM64。
- 公共账本优先，金额按分精确分摊，区分消费和转账。实现自动卫生轮换、打卡、换班与公共物资采购账单。
- 缺少工具链时提供对应发行版的安装命令，由用户安装。分析、测试、构建和启动结果以实际命令为准。

## 维护与人工复核

- 检查固定小数与整数分的转换以及付款方、参与方和实际转账的对应关系。
- 用真实宿舍数据试用前，核对系统日期和成员名单。试用后关闭再打开以检查数据保留。
- Windows 建议在目标主机从原生目录验证完整 Release 目录。Android 建议在 ARM64 真机验证输入法、返回键、打卡、安装和数据保留。
- 多设备同步接入前需要补充身份、共享规则、离线冲突处理、版本迁移和操作审计约定。

## 设备 SSH 密钥迭代

用户要求将 Git 和密钥管理放入应用。DormOS 沿用随包发布的 libgit2 和 SSH 运行库，通过 Dart cryptography 生成 Ed25519 密钥，并按 OpenSSH 格式编码。设备私钥沿用本地凭据目录的操作系统访问限制。仓库配置记录密钥来源，数据库升级保留原先导入密钥的默认行为与同步基线。界面可生成设备密钥、复制公钥并选择同步凭据。回归用例覆盖界面复制、设备密钥复用、旧版配置迁移和本地 Git 同步流程。

## .dorm 邀请迭代

用户要求将仓库和凭据打包成可快速分享的文件。实现版本化的 .dorm 格式，默认仅包含仓库地址。共享私钥时，用随机盐和 PBKDF2-HMAC-SHA256 派生邀请密钥，再以 AES-256-GCM 加密私钥和原 SSH 口令。仓库地址经认证数据绑定。导入后通过现有配置表单确认，并沿用本地凭据保护。回归测试覆盖文件往返、大小和结构限制、错误口令及仓库字段篡改。

## 账单个人费用迭代

用户要求同一笔垫付中区分均摊的公共开销和指定成员个人开销。公共费用继续按整数分均摊，再将每人个人费用并入其应付。迁移为历史分摊补零，保持原金额、付款人与实际转账。Git 快照没有个人费用时沿用旧格式，有个人费用时写入新版字段。验证覆盖个人费用独立归属、部分结算、旧数据库与双端 Git 同步。

## 云同步代理迭代

用户要求支持 SOCKS 与 HTTP 代理。实现 SOCKS5 和 HTTP CONNECT，支持可选用户名和密码。由于内置 Git 使用 SSH，Dart 为单次 Git 操作建立临时回环隧道，再只改写内存中的拉取和推送端点。SSH 指纹仍按 GitHub 固定指纹核验。代理设置沿用本机凭据目录，仓库和邀请文件无需迁移。

## 统一设置与公钥显示

将外观、成员、卫生任务和云同步集中到顶部齿轮入口。宽屏采用双栏，窄屏采用单列。云同步按连接、设备密钥、代理与邀请组织，公钥在界面以星号遮挡中段。Widget 回归测试检查遮挡后的展示、完整公钥复制、设置导航与主题切换。

## 品牌更名

自 v0.8.0 起，应用名称为 Dorm，全称使用用户指定的 Dorm Organizes Roomates' Matters。更新了界面、Windows 程序与文件属性，以及 Linux 和 Android 的可见名称。Windows 数据存储沿用旧版路径，因此可以读取原有数据库、SSH 凭据和代理设置。仓库同步标识和 .dorm 邀请格式亦延续使用。
