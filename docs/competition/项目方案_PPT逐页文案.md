## 第 3 页：痛点分析 —— 寝室协作的“四大高频摩擦”
* **核心观点**：寝室共同生活高频琐碎，现有工具（微信接龙/纯云端小程序）难以兼顾算账精度与隐私离线需求。
* **四象限痛点卡片**：
  1. **混合账务难算清**：一人垫付公共餐费 + 替室友代付个人物品，小数分摊有误差，月末集中对账易扯皮。
  2. **排班物资易脱节**：值日靠口头易忘、换班麻烦；公共耗材断货不知情，采购与记账两张皮。
  3. **多端割裂与隐私顾虑**：手机随手记、电脑集中算无法打通；不愿将日常消费上传第三方商业服务器。
  4. **校园网/无网受限**：传统云端工具断网即瘫痪，缺乏轻量局域网协同手段。

## 第 4 页：产品定位与整体闭环
* **一句话定位**：*Dorm Organizes Roomates' Matters* —— 本地优先、可选端到端加密云同步、支持局域网即扫即用的三端寝室协作应用。
* **核心闭环图（左输入 → 中处理 → 右输出）**：
  * **输入**：日常垫付/代付、值日规则、物资耗材、待办事项、破冰互动
  * **处理**：整数分精确分摊、游标自动轮换、单事务采购入账、三端状态同步
  * **输出**：结算核销清单、月度消费趋势、CSV/SQLite 备份、可视化看板

## 第 5 页：核心模块一 —— 公共账本与结算中心
* **左侧文字**：
  * **混合记账**：同一账单内同时支持“公共均摊”与“指定个人代付”，底层以**整数分**存储与余分守恒分配。
  * **结算中心**：按付款方向自动聚合待还账单，支持登记一笔转账从最旧账单依次核销。
  * **月度分析**：近 6 个月趋势图 + 本机预算线 + 一键导出 CSV / 复制催收清单。

## 第 8 页：核心模块四 —— 离线优先与双模协同架构
* **核心对比图（三种使用模式自由切换）**：
  * **单机离线**：本机 SQLite 存储，零网络零账号可用，支持 `.dormbak` 备份。
  * **局域网工作台**：桌面端一键启 HTTP 服务 + 二维码，室友手机浏览器免安装直接读写。
  * **GitHub 私有云同步**：内置 `libgit2` + `Ed25519` 设备密钥，`.dorm` 口令加密分享与二维码导入，支持代理与冲突并列解决。

## 第 9 页：技术架构与工程实现路径
* **四层清晰架构图**：
  * **UI 表现层（`lib/ui/`）**：Material 3 宽/窄屏响应式布局 + 内置 `NotoSansSC` 中文字体 + 快捷键 `Ctrl+1~5` / `F11`。
  * **牌桌引擎层（`lib/game/`）**：共用牌型规则、UDP 发现、HTTP 网页服务与 X25519+AES-GCM 加密通道。
  * **数据与传输层（`lib/data/`）**：SQLite 事务仓储、SSH 凭据目录权限隔离、代理隧道。
  * **纯 Dart 领域层（`lib/domain/`）**：整数分计算、轮换游标、同步合并协议，与界面彻底解耦。

## 第 11 页：关键 Prompt 设计与迭代案例（一）
* **展示结构：Prompt 意图 → AI 产出 → 人工核查发现的问题 → 迭代修正**
* **案例 A（Linux 移植与窗口通道）**：
  * 需求：为原 Windows/Android 项目补齐 Linux 桌面支持。
  * 核查修正：发现 GTK 文件保存对话框不会像 Windows 自动补全扩展名，人工实测报错后迭代 `save_document.dart` 自动补全与后缀拦截逻辑；并在 `my_application.cc` 补齐 `F11` 全屏 `MethodChannel`。
* **案例 B（全平台隐患排查）**：
  * 修复 Android 头像选择器过滤兼容问题，以及局域网发现 `NetworkInterface.list` 异步挂起期间的 Socket 竞态关闭风险。

## 第 12 页：关键 Prompt 设计与迭代案例（二）—— 体验升级
